> no frameworks, no JavaScript dependencies. Crafted at 13 years old while
> experimenting with CSS animations and creative layout mechanics.

---

## 📦 What's Inside

| # | Menu Name | Mechanic |
|:---:|---|---|
| 1 | **Aside Menu** | Slides in from the side |
| 2 | **Radial Menu** | Circular fan-out from a focal point |
| 3 | **Full-Page Menu** | Full-screen overlay on trigger |
| 4 | **Circle Aside Menu** | Expands from a circular anchor |
| 5 | **Switch Window Menu** | Content shifts to reveal menu behind |
| 6 | **Animated Menu** | Hamburger morphs into ✖ via keyframes |

## 🛠️ Tech Stack

| Technology | Role |
|---|---|
| `HTML5` | Structure and markup |
| `CSS3 Transitions` | Smooth open/close animations |
| `CSS Keyframes` | Hamburger → ✖ morphing |
| `CSS Variables` | Easy theming and customization |
| `:checked` trick | Toggle state without JavaScript |
