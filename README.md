A collection of **interactive hamburger menu designs** built with **HTML & CSS**.  
This was a something I built when I was **13 years old**, experimenting with menu layouts and CSS animations.  

---

## 📌 Overview

This collection showcases a variety of navigation menus that you can use or adapt in your own projects.  
Menus include:

- **Aside Menu** – A sliding sidebar navigation.  
- **Radial Menu** – Circular fan-out menu for floating action buttons.  
- **Full-Page Menu** – Overlay menu covering the entire screen.  
- **Circle Aside Menu** – Sidebar that expands from a circular anchor.  
- **Switch Window Menu** – Content shifts to reveal menu behind.  
- **Animated Menu** – Hamburger icon transforms into an 'X'.
